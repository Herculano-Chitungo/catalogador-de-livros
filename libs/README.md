# Catalogador de Livros

Aplicação para gerenciamento de acervo de livros desenvolvida com Angular, Node/NestJS e MongoDB.

## Como rodar o projeto localmente

### 1. Pré-requisitos
Certifique-se de ter instalado em sua máquina:
- Node.js
- Docker e Docker Compose (caso queira rodar o banco localmente)

### 2. Clonar o repositório
```bash
git clone [https://github.com/seu-usuario/catalogador-de-livros.git](https://github.com/seu-usuario/catalogador-de-livros.git)
cd catalogador-de-livros
